RESEARCH EXPERTS - KNOWLEDGE BASE DESCRIPTION

OVERVIEW
This repository contains a refined, NLU-optimized knowledge base designed for chatbot integration, website FAQs, and AI training. The knowledgebase.json file consists of 221 FAQ items covering core academic services.

CORE SERVICES COVERED
1. AI Detection & Reduction: Turnitin reports, asterisk (*) symbol logic, and reducing AI scores.
2. Plagiarism Removal: Manual rewriting, LaTeX support, and similarity score reduction.
3. Data Analysis: SPSS, Statistics, data cleaning, and interpretation.
4. Trust & Privacy: Document safety, data retention, and repository settings.

KEY FEATURES
- NLU Ready: 3-4 natural language variations per question for better bot recognition.
- Balanced Tone: Professional yet accessible responses for technical and non-technical users.
- Optimized Schema: Stripped of obsolete fields (display_on, status, sort_order).
- Search Optimized: Normalized lowercase tags for improved search accuracy.

DATA STRUCTURE (JSON FIELDS)
- intent: Unique identifier for the question (e.g., interpret_turnitin_asterisk).
- category: High-level grouping (e.g., billing_pricing).
- service: Specific service area (e.g., ai_reduction).
- question: The primary user question.
- answer: The refined, plain-text answer for both bot and web use.
- tags: Keywords for search indexing.
- variations: Alternative phrasing for NLU training.

USAGE GUIDE
- Bot Training: Use 'variations' for intent training.
- Dynamic FAQ: Use 'category' for website groupings.
- Chat Responses: Use 'answer' for clean messaging app replies.
